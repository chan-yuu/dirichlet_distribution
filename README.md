# Dirichlet / Evidential Demos

This repository contains two pure-Python demos:

1. `demos/routeA_edl_demo`
   - Route-A EDL training comparison and visualization.

2. `demos/evidential_feasibility_demo`

Each demo has its own `README.md` and `requirements.txt`.
